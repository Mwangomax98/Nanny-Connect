# tai – Pride of Africa website

Product catalogue for **tai – Pride of Africa** (Magila Street, Ilala, Dar es Salaam). Visitors browse products and send an enquiry on WhatsApp. The owner manages products in the admin at `/admin`.

**Stack:** Next.js 16 (App Router, TypeScript, Tailwind CSS 4) + Payload CMS 3 in one app, PostgreSQL 17, Docker.

## Run it on your computer

You need: [Node.js 22](https://nodejs.org), [pnpm](https://pnpm.io/installation) and [Docker Desktop](https://www.docker.com/products/docker-desktop/).

1. Copy the example settings: `cp .env.example .env`
2. Put a long random value in `PAYLOAD_SECRET` inside `.env` (for example the output of `openssl rand -hex 32`).
3. Start the database: `docker compose up -d`
4. Install packages: `pnpm install`
5. Create the database tables: `pnpm migrate`
6. Start the site: `pnpm dev`
7. Open http://localhost:3000 for the website and http://localhost:3000/admin to create the first admin user.

## Useful commands

| Command                        | What it does                                         |
| ------------------------------ | ---------------------------------------------------- |
| `pnpm dev`                     | Run the site locally with live reload                |
| `pnpm lint` / `pnpm typecheck` | Check code quality and types                         |
| `pnpm format`                  | Auto-format all files                                |
| `pnpm test:int`                | Integration tests (needs the database running)       |
| `pnpm test:e2e`                | Browser tests (starts the dev server)                |
| `pnpm build`                   | Production build                                     |
| `pnpm migrate:create <name>`   | Create a migration after changing collections/fields |
| `pnpm migrate`                 | Apply pending migrations                             |
| `pnpm generate:types`          | Regenerate `src/payload-types.ts`                    |

**When you change a collection or field:** run `pnpm migrate:create <short-name>`, then `pnpm generate:types`, and commit the new files in `src/migrations/`. Production applies pending migrations automatically when the app starts.

## Production image

`docker build -t tai-website .` builds a small standalone image. At runtime it needs `DATABASE_URL`, `PAYLOAD_SECRET` and `NEXT_PUBLIC_SERVER_URL`, and a volume mounted on `/app/media` for uploaded images. `GET /api/health` returns `{"status":"ok"}` when the app and database are up.

## Folders

```
src/app/(frontend)   public website pages
src/app/(payload)    admin panel and API (generated by Payload)
src/collections      content types (Users, Media; Products etc. coming next)
src/migrations       database migrations (commit these)
reference/           prototype and photos (not deployed)
tests/               integration (vitest) and browser (Playwright) tests
```
